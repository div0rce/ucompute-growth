# Handoffs to other workstreams

Growth does not edit the engineering, Core Lab or website repositories. When another workstream must implement something, Growth writes a dated proposal here: `YYYY-MM-DD-<workstream>-<topic>.md`, with the ask, the evidence, the exact text or assets, and the claim ids it rests on. The owner or that workstream picks it up in their own session; Growth records the outcome in `journal/LOG.md` and marks the file `status: accepted | declined | superseded` in its front matter.
